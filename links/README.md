# Links para a bio

Página estática em `/links/`, sem dependências externas.

Edite `slots.js` para alterar título, subtítulo, imagem, destino e ordem. Apenas os cinco primeiros itens com `enabled: true` aparecem. `url: null` mantém o card visível, identificado como pendente e sem clique. A validação permite somente URLs HTTP/HTTPS.

Glyph aponta para https://www.glyph.life/; basta trocar o campo `url` pelo endereço confirmado da Play Store no lançamento. Hotmart e os dois canais usam os links enviados pelo responsável em 24/10/2026. Somente Tarot continua sem destino.

O acesso ao BecosLab é um link de texto separado, centralizado no rodapé. A arte de Frequências Sagradas usa provisoriamente a imagem existente do Studio. A coroa do Mapa do Império foi copiada para esta pasta para não depender dos arquivos privados do curso.

Validação local: cinco cards, imagens carregadas, destinos de Glyph e BecosLab conferidos no DOM, sem transbordamento horizontal na largura disponível no navegador. Não publicado.
